# PaTH Digital Studio

Homepage for **PaTH Digital Studio** — a software development studio building MVPs, websites, web apps, mobile apps and prototypes for brands and companies.

## Stack

- Next.js App Router
- TypeScript
- React
- Plain CSS

## Portfolio data

Project cards are data-driven. Edit `src/data/projects.ts` to add, remove, reorder or feature products without rewriting the card component.

Set `featured: true` for a project to show it on the homepage. `ProjectCard.tsx` renders each entry from the same metadata structure.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
